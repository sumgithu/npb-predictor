# NPB Predictor & Standings Analytics

プロ野球（NPB）セ・パ両リーグの自力優勝チャンピョンシップナンバー（CN）、クリンチ状況、および全143試合完走モンテカルロ・シミュレーションによる順位・優勝確率をリアルタイムに解析するWebアプリケーションです。

---

## 🚀 主な機能 (Key Features)

1. **チャンピョンシップナンバー（CN / Championship Number）**
   - 従来のマジックナンバーと異なり、他球団の自力優勝が残っている段階でも全球団に対して常時確定数を算出。
   - 自力優勝消滅後も、数学的な可能性が残る限り「逆転に必要な勝数」を継続表示（◇枠囲み数値）。
2. **全143試合完走モンテカルロ・シミュレーション（3,000回）**
   - シーズン残日程について、チーム通算得失点力・ホームアドバンテージ・球場特性を考慮して3,000回のシーズン完走シミュレーションを実行。
   - 各球団の最終順位確率分布、優勝決定日確率、優勝ラインテーブルを算出。
3. **試合別予想勝利確率（Log5法 & ベイズ先発補正）**
   - 球場パークファクター連動のピタゴラス期待勝率と、登板実績に基づく予告先発投手の動的ベイズ補正を組み合わせた確率算出。
4. **日付巻き戻し解析（カレンダー機能）**
   - シーズン開幕日から現在までの過去任意の基準日における順位表・CN・対戦成績表を完全再現。

## 📐 数理・統計モデル (Mathematical Models)

本システムでは、再現性の乏しい直近の短期的偏り（勢い・好不調ノイズ）を排除し、セイバーメトリクスのエビデンスに基づく統計モデルを採用しています。

### 1. チーム基礎力評価（ピタゴラス期待勝率）
シーズン通算の総得点（$RS$）および総失点（$RA$）を基礎とし、消化試合数が少ない序盤は前年度実績（2025年）を事前分布とする経験ベイズ回帰（Empirical Bayes Regression）を適用しています。
$$W_{\text{Pyth}} = \frac{RS^\gamma}{RS^\gamma + RA^\gamma}$$
※ 指数 $\gamma$ は球場パークファクター（PF）に応じて動的に伸縮（基礎値 1.83）。

### 2. 球場パークファクター（Park Factor）
NPB各本拠地球場の得点環境係数を組み込み、ピッチャーズパーク（甲子園・バンテリンドーム等）とヒッターズパーク（神宮・横浜等）における得失点環境および好投手の支配力（レバレッジ）を補正しています。

### 3. Log5対戦確率とNPBホームアドバンテージ
両チームの中立期待勝率をLog5方程式で合成し、NPBの歴史的実測値に基づくホームアドバンテージ（オッズ比 約1.15 / 勝率約53.5%）を乗算して各試合の勝率を算出します。

### 4. 先発投手の動的ベイズ補正（当日の試合予想）
当日の試合予想では、通算登板実績（$W, L$）に対して平均的な投手（4勝4敗）を事前分布としたラプラス平滑化（ベイズ収縮推定量）を適用し、対戦オッズを補正しています。
$$P_{\text{pitcher}} = \frac{W + 4.0}{(W + L) + 8.0}$$
※ シーズン完走シミュレーション（優勝確率）では、先発ローテーションの予測バイアスを排除するためチーム基礎力モデルに基づき一貫した評価を行っています。
