# NPB Predictor & Standings Analytics プロ野球（NPB）セ・パ両リーグの自力優勝チャンピョンシップナンバー（CN）、クリンチ確定状況、および全143試合完走モンテカルロ・シミュレーション（5,000回）による優勝確率・順位確率をリアルタイムに解析・可視化するWebシステムです。 --- ## 🚀 主な機能 (Key Features) 1. **チャンピョンシップナンバー（CN / Championship Number）** - 他球団の自力優勝が残っている段階でも、全球団に対して常時確定数を算出。 - 自力優勝が消滅した場合でも、数学的な可能性が残る限り「逆転に必要な最小勝数」を継続表示（◇枠囲み数値）。 2. **全143試合完走モンテカルロ・シミュレーション（5,000 runs）** - シーズン残日程について、攻撃力・守備力のポアソン得失点モデル、球場得点環境（パークファクター）、ホームアドバンテージ、休養日数差、および実測引き分け率を反映したシミュレーションを実施。 - 最終順位確率分布、優勝決定日確率、優勝ラインテーブルを算出。 3. **試合別予想確率（ポアソン得失点モデル）** - 各チームの攻撃力・守備力パラメータから対戦ごとの期待得点を算出し、勝・分・敗の3分岐確率を算出。 - 予告先発投手が確定している試合のみ、先発投手の登板実績によるベイズ収縮補正を適用。 4. **日付巻き戻し解析（カレンダー機能）** - シーズン開幕日から現在までの過去任意の基準日における順位表・CN・対戦成績表（H2H）を完全再現。 - 過去時点の解析では、その日以降の未来データを用いずに当時の情報のみで再計算。 --- ## 📐 数理・統計モデル (Mathematical Models) 本システムでは、セイバーメトリクスのエビデンスに基づき、直近の成績推移と長期的な実力値をバランスよく反映する統計モデルを採用しています。 ### 1. ポアソン攻撃・守備力モデル（Opponent-Adjusted Poisson Model） 各試合のチーム得点をポアソン分布に従う確率変数としてモデル化します。 - チームごとの「攻撃力パラメータ」および「守備力パラメータ」をAdamオプティマイザにより最尤推定。 - 直近の試合ほど重視されるよう、半減期（50日）を設けた指数加重（Recency Weighting）を適用。 - 過去シーズン（2016年〜2025年）の通算実績を事前分布（Prior）として利用し、標本数が少ない開幕直後の過剰適合を防止。 ### 2. 球場環境とホームアドバンテージ - 過去データから各本拠地球場の得点環境係数（Park Factor）を推定し、ヒッターズパーク・ピッチャーズパークの特性を補正。 - ホーム球団の得点期待値に対し、実測値に基づくホームアドバンテージ係数を乗算。 ### 3. 先発投手と休養日数の動的補正 - **先発投手補正**: 先発投手が確認済みの試合に限り、通算登板実績をベイズ収縮させた補正項を適用（未定の将来日程には適用せず未来情報リークを防止）。 - **休養日数差**: 前回の試合からの間隔（連戦・休養日）の差に応じたロジスティック補正を勝敗オッズに反映。 ### 4. シーズン序盤のモデル不確実性バンド 開幕直後など消化試合数が少ない時期は、パラメータ推定の不確実性を考慮し、モデルを揺らした複数シナリオのシミュレーション結果（パーセンタイル範囲）を「優勝可能性の幅」として提示。 --- ## 📂 リポジトリ構成 ```text ├── .github/workflows/ │ └── update_clinch.yml # 自動集計＆更新ワークフロー ├── clinch_engine.py # 数理モデル解析・シミュレーション・JSON生成エンジン ├── backtest.py # モデル予測精度のバックテスト・較正検証スクリプト ├── convert_log.py # テキストログ・CSV変換スクリプト ├── standings.html # メイン公開ダッシュボード（フロントエンド） ├── admin.html # 試合結果入力・手動管理インターフェース ├── games_db.json # 2026年レギュラーシーズン試合データベース（正本） ├── history_standings.json # 各日順位表・シミュレーションデータ（エンジン出力） └── README.md # 本ドキュメント
